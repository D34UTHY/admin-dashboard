# admin-dashboard
Dashboard Administrativo com informações de vendas

Projeto estático baseado em um dashboard desenvolvido por mim anteriormente que colhia dados de vendas em tempo real de uma outra aplicação Web utilizaada por um cliente. Estilização moderna com HTML, CSS e JavaScript de um dashboard administrativo totalmente responsivo com alternância rápida de tema. Essa versão se trata de uma versão minimalista e pouco funcional a respeito do dashboard, pois, a intenção é apenas conhecer o estilo do design que utilizo.

Para melhor visualização, acesse o Github Pages: https://d34uthy.github.io/admin-dashboard
